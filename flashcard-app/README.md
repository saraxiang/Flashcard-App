# 🏇 Horse Racing Game

An exciting and interactive horse racing game built with Next.js, React, and Tailwind CSS!

## 🎮 Features

- **5 Unique Horses**: Choose from Thunder 🐎, Lightning 🐴, Storm 🏇, Blaze 🦄, or Spirit 🎠
- **Betting System**: Place bets on your favorite horse with different odds (2:1 to 6:1)
- **Real-time Racing**: Watch the horses race across the screen with smooth animations
- **Balance Tracking**: Start with $100 and grow your balance by winning races
- **Race History**: Track your wins and losses with a detailed race history
- **Beautiful UI**: Modern, responsive design with gradient backgrounds and smooth animations

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to play the game!

## 🎯 How to Play

1. **Select a Horse**: Click on one of the 5 horses to select it for betting
2. **Set Your Bet**: Choose how much you want to bet (must be within your balance)
3. **Start the Race**: Click "Start Race!" to begin
4. **Watch and Win**: Watch the horses race to the finish line
5. **Collect Winnings**: If your horse wins, collect your winnings based on the odds!

## 🏆 Odds

- Thunder 🐎: 3:1
- Lightning 🐴: 4:1
- Storm 🏇: 2:1 (favorite)
- Blaze 🦄: 5:1
- Spirit 🎠: 6:1 (longshot)

## 🛠️ Tech Stack

- **Next.js 14**: React framework with App Router
- **React 18**: UI library with hooks
- **Tailwind CSS**: Utility-first CSS framework
- **Framer Motion**: Animation library (available in dependencies)
